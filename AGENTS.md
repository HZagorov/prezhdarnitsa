## Formatting and Code Style
- Do not make formatting-only changes unless explicitly requested.
- Preserve the existing formatting, indentation, whitespace, and line endings of modified files.
- Do not reformat entire files or unrelated code sections when making changes.
- Keep code changes minimal and limited to the requested functionality.
- Do not modify existing naming conventions or coding style just to make them consistent with personal preferences.
- If a code change requires modifying an existing line, preserve its original formatting style.
